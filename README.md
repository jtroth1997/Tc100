# TC100 website

Public-facing website for the TC100 independent tile community.

The first release includes tailored journeys for homeowners, tilers and independent retailers; a future-ready directory search interface; practical homeowner guidance; membership calls to action; and a clearly separated preview of forthcoming member accounts.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy

The site is static and can be deployed directly with GitHub Pages, Cloudflare Pages, Netlify or Vercel.
